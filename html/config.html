Información importante de configuración

Durante el examen trabajará con varios sistemas virtuales además del escritorio en el que está sentado. No tiene acceso root al sistema de escritorio, sin embargo tiene acceso root completo a los sistemas virtuales.

Información del Sistema

Trabajará con los siguientes sistemas virtuales para este examen:

Sistema    Dirección IP
node1.domain.example.com 172.25.250.10
node2.domain.example.com 172.25.250.11

Los sistemas con los que trabaja son miembros del dominio DNS domain.example.com. Todos los sistemas en este dominio están en la 172.24.14.0/255.255.255.0 subred y todos los sistemas en esa subred están en domain.example.com.

Las direcciones IP listadas para estos sistemas son las direcciones que deberían ser asignadas al sistema. Puede ser necesario configurar la red para uno o ambos de sus sistemas para poder alcanzarlos en la dirección listada arriba.

Información de Cuenta

La contraseña de root para node1 ha sido establecida como "radiowits"

A menos que se especifique lo contrario, esta será la contraseña que use para acceder a otros sistemas y servicios. También, a menos que se especifique lo contrario, debe usar esta contraseña para cualquier cuenta que cree o para cualquier servicio que requiera que se establezca una contraseña.
